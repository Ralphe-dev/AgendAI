# Requisitos do Sistema

## Requisitos Funcionais (RF)
- **[RF01]** O sistema deve permitir adicionar um título, data e hora do compromisso.
- **[RF02]** O sistema deve listar todos os compromissos agendados.
- **[RF03]** O sistema não deve permitir dois compromissos no exato mesmo horário.

## Requisitos Não Funcionais (RNF)
- **[RNF01]** O controle de versão deve utilizar Git Flow e Conventional Commits.
- **[RNF02]** A interface deve ser simples (execução via terminal/console para o protótipo inicial).
