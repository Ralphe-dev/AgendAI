# Project Charter: AgendAI

## Visão Geral
Um sistema inteligente e leve para agendamento de compromissos pessoais e profissionais, evitando conflitos de horários.

## Objetivos SMART
- Entregar a especificação e o fluxo do projeto em 1 dia.
- Permitir o cadastro básico de compromissos.

## Escopo
- **Dentro:** Cadastro, listagem e exclusão de compromissos.
- **Fora:** Integração com Google Calendar, envio de emails.

## Stakeholders
- Usuário final (Pessoa Física ou Profissional Autônomo).
